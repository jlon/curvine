└────────────────────────┬────────────────────────────────────────┘
                         │

┌─────────────────────────────────────────────────────────────────┐
│                    内核 FUSE 驱动                                │
│  - 接收read()请求                                                │
│  - 生成FUSE_READ请求                                             │
│  - 通过/dev/fuse发送到用户态                                      │
└────────────────────────┬────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│              FUSE 用户态守护进程 (curvine-fuse)                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │ FuseReader::read()                                       │   │
│  │   ↓                                                      │   │
│  │ UnifiedReader::fuse_read()                               │   │

## 关键差异对比表

| 维度 | FUSE | NFS | 差异倍数 |
|------|------|-----|---------|
| **数据拷贝次数** | 0-1次 | 10次 | 10x |
| **协议层数** | 1层 (FUSE) | 4层 (NFS+RPC+XDR+TCP) | 4x |
| **内核态处理** | 是 | 否（用户态RPC） | - |
| **零拷贝支持** | 是 (splice) | 否 | - |
| **并发模型** | 内核多线程 | 用户态ReaderPool | - |
| **单线程延迟** | ~100μs | ~500μs | 5x |
| **8线程扩展性** | 13.7x | 4.0x | 3.4x |
| **8线程带宽** | 13005 MiB/s | 2287 MiB/s | 5.7x |

## 性能瓶颈分析

### FUSE 性能优势来源

1. **零拷贝路径**
   - 使用splice()系统调用
   - 数据直接从页缓存传输到用户空间
   - 避免用户态/内核态拷贝

2. **内核态并发**
   - 内核FUSE驱动可以并行处理多个请求
   - 充分利用多核CPU
   - 无锁竞争

3. **无协议开销**
   - 本地文件系统接口
   - 无需RPC/XDR编解码
   - 无TCP/IP栈开销

### NFS 性能瓶颈

1. **多次数据拷贝**
   - XDR编码强制拷贝（build_read_response）
   - RPC层拷贝
   - TCP/IP栈拷贝
   - 总计10次拷贝

2. **协议开销**
   - RPC编解码（CPU密集）
   - XDR格式化（必须对齐、填充）
   - TCP/IP协议处理

3. **并发限制**
   - ReaderPool只有8个reader
   - 8线程竞争8个reader
   - 锁竞争导致性能下降

4. **用户态处理**
   - RPC处理在用户态
   - 上下文切换开销
   - 无法利用内核优化

## 结论

NFS和FUSE之间5.7x的性能差距是**架构本质决定的**，不是实现问题：

1. **FUSE是本地文件系统**：内核直接支持，零拷贝，无协议开销
2. **NFS是网络协议**：必须经过完整的RPC/XDR/TCP处理，多次拷贝

这个差距是**合理的**，符合两种架构的设计目标：
- FUSE：追求本地访问的极致性能
- NFS：追求网络访问的标准兼容性

通过优化（增加ReaderPool、减少拷贝、使用RDMA），NFS可以缩小差距到2-3x，但无法完全消除。
